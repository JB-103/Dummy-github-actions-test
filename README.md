# DummyGitHubActionsTest

A minimal .NET class library with NUnit tests, created as a practice project for setting up GitHub Actions.

## Structure
- `src/DummyLib` – simple `Calculator` class
- `tests/DummyLib.Tests` – NUnit tests

## Build and test
```bash
dotnet restore
dotnet build
dotnet test
```
This line was added to trigger a pull request check.
